Форма менеджера агента

Предназначена для запуска задач LEARN / LEARN AND PREDICT / PREDICT / DELETE.

Подсказки по заполнению
  • LEARN — использует данные из базы для обучения и сохранения модели в базе агента. Обученная модель сохраняется в базе.
  • PREDICT — читает модель из базы и предсказывает метки для данного оборудования. Результат сохраняется в базе.
  • LEARN AND PREDICT — объединяет оба шага.
  • DELETE — очищает данные по прошлому опыту анализа для данного оборудования.
